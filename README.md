# FLM 26 — Football Life Manager 26

O manager de futebol definitivo. Monte seu elenco, desenvolva jovens talentos e leve seu clube ao topo.

## Stack

- React + Vite + TypeScript
- Tailwind CSS
- Backend gerenciado (PostgreSQL + RLS + Edge Functions)

## Desenvolvimento local

```sh
npm install
npm run dev
```

## Build de produção

```sh
npm run build
```
